## Key Contributions
* **9D Feature Engineering Pipeline**: Processes multi-sheet e-learning data into rich behavioral features.
* **K-Means Clustering (k=4)**: Groups learners into four personas: Casual Explorers, Deep Specialists, Frequent Learners, and Budget Beginners.
* **Streamlit Dashboard**: A web interface for real-time segmentation, visual exploration, and peer-based course recommendations.

## Repository Structure
* `paper.pdf` - Full-text research paper.
* `app.py` - Core Streamlit application dashboard code.
* `requirements.txt` - Required Python packages.

## How to Run the App
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the dashboard: `streamlit run app.py`
